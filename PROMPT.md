# Prompt

Used in the Cursor desktop app with **Gemini 4 Argon (High)**, agent running locally on a MacBook.

```
Baue mir in diesem Workspace eine kleine, aber beeindruckende Web-App in reinem HTML, CSS und JavaScript (ohne Frameworks): eine interaktive 3D-Partikel-Galaxie in Canvas/WebGL.

Anforderungen:
1. Lege einen Ordner `argon-demo/` an, darin `index.html`, `style.css` und `main.js`.
2. Mindestens 20.000 Partikel als Spiralgalaxie, die sich flüssig mit 60 FPS drehen.
3. Steuerung: Maus zum Drehen, Mausrad zum Zoomen, Leertaste für Pause, Taste "R" für eine neue zufällige Galaxie.
4. Ein kleines UI-Panel oben rechts mit Slidern für Partikelanzahl, Armanzahl, Drehgeschwindigkeit und Farbschema (live, ohne Neuladen).
5. FPS-Anzeige unten links.
6. Sauberer, kommentierter Code.

Danach Computer Use:
7. Starte einen lokalen Server im Ordner (z. B. `npx serve argon-demo` oder `python3 -m http.server`).
8. Öffne die Seite im Browser, mach einen Screenshot und prüfe selbst, ob alles richtig angezeigt wird.
9. Teste jeden Slider und jede Taste wirklich per Maus und Tastatur, mach nach jedem Test einen Screenshot.
10. Wenn etwas nicht funktioniert oder ruckelt: Fehler finden, beheben, erneut testen.
11. Zum Schluss: kurze Zusammenfassung, was du gebaut, getestet und korrigiert hast, plus den finalen Screenshot.
```

English summary: build an interactive WebGL spiral galaxy (20k+ particles, 60 FPS) in vanilla HTML/CSS/JS with mouse rotate/zoom, Space to pause, R to randomize, a live slider panel and an FPS counter — then use computer use to serve it, open it in the browser, test every control with screenshots, and fix what breaks.
